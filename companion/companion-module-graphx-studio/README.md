# graphX Studio — module Companion

Module local pour Companion **5.1+ (API 2.2)**. Voir [companion/HELP.md](companion/HELP.md).

Développement : `npm ci`, `npm test`, `npm run package` avec Node 22.20+.
Le dossier `pkg` construit peut être placé dans le dossier de modules développeur de Companion, sans installer Node ni les dépendances sur le poste d’utilisation.
